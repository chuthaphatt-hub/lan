ABOUT THE PROJECT

อัตลักษณ์ความเป็นล้านนาในเมืองเชียงใหม่

แผนที่นี้ชวนสำรวจร่องรอยของกาแล โคม และอักษรล้านนาที่ตรวจพบจากภาพ Google Street View

พื้นที่ศึกษา
เขตเทศบาลนครเชียงใหม่
วิธีตรวจจับ
YOLO Object Detection
การวิเคราะห์
Average Nearest Neighbor, Kernel Density และ Getis-Ord Gi*

จุดบนแผนที่คือผลการตรวจพบเชิงพื้นที่ ไม่ใช่รายชื่อสถานที่ท่องเที่ยวที่ได้รับการรับรอง
